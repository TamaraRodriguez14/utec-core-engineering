# Python - Manejo de excepciones

Ejercicios sobre manejo de errores con `try` / `except` en Python.

## Archivos

| Archivo | Descripción |
|---|---|
| `safe_print_list.py` | Imprime hasta `x` elementos de una lista en una línea y devuelve cuántos imprimió realmente. |
| `safe_print_integer.py` | Imprime un entero con `{:d}` y devuelve `True`, o devuelve `False` si el valor no es un entero. |
