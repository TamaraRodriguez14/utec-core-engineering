# Python - Funciones y modularidad

Ejercicios sobre definición de funciones, valores de retorno, diferencia entre
`print` y `return`, ejecución de scripts e importación entre archivos usando
`if __name__ == "__main__":`.

## Archivos

| Archivo | Descripción |
|---|---|
| `islower.py` | Devuelve `True` si un carácter es una letra minúscula (lógica ASCII). |
| `uppercase.py` | Imprime una cadena en mayúsculas usando `ord()` y `chr()`. |
| `print_last_digit.py` | Imprime y devuelve el último dígito de un número. |
| `pow.py` | Devuelve `a` elevado a `b` con un bucle, sin usar `**`. |
| `simple_add.py` | Define `add(a, b)` y la ejecuta solo si el archivo se corre directamente. |
| `test_import.py` | Importa `simple_add` para observar el comportamiento al importar. |
| `add_0.py` | Define la función `add(a, b)`. |
| `add.py` | Importa `add` desde `add_0.py` e imprime `1 + 2 = 3`. |
