# Python - Clases y modelo de objetos

Ejercicios sobre clases, instancias, atributos, métodos y encapsulamiento en Python.
| `0-square.py` | Define una clase vacía `Square` que representa un cuadrado. |
| `1-square.py` | Define `Square` con un atributo de instancia privado `__size` inicializado en `__init__`. |
| `2-square.py` | `Square` con `size` privado validado: debe ser entero y mayor o igual a 0. |
| `3-square.py` | `Square` con `size` validado y un método `area()` que devuelve el área. |
| `4-square.py` | `Square` con getter y setter para `size` (validado en el setter) y `area()`. |
