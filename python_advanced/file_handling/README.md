# Python - Manejo de archivos

Ejercicios sobre lectura y escritura de archivos en Python usando `with`.

## Archivos

| Archivo | Descripción |
|---|---|
| `read_file.py` | Lee un archivo de texto UTF-8 y lo imprime en stdout. |
| `write_file.py` | Escribe una cadena en un archivo UTF-8 (lo crea o sobreescribe) y devuelve los caracteres escritos. |
| `append_write.py` | Agrega una cadena al final de un archivo UTF-8 (lo crea si no existe) y devuelve los caracteres agregados. |
